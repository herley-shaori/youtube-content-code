# S3 website

Tutorials on serving a static website from Amazon S3, built in the Jakarta Region
(`ap-southeast-3`). Each use case has its own folder with the infrastructure code in
`terraform/`.

| Use case | What it shows |
| --- | --- |
| [static-website](static-website/) | A static website served from the S3 website endpoint, with Cloudflare as the only public entrance |
