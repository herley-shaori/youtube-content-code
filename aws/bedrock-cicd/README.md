# Bedrock CI/CD

Tutorials on building, testing, and deploying Amazon Bedrock applications with CI/CD
in the Jakarta Region (`ap-southeast-3`). Each use case has its own folder with the
application code in `app/` and the infrastructure code in `terraform/`.

| Use case | What it shows |
| --- | --- |
| [bedrock-hr-assistant](bedrock-hr-assistant/) | An HR leave assistant deployed with GitHub Actions, OIDC, Terraform, Lambda, and Amazon Nova Lite |
