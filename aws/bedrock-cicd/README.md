# Bedrock CI/CD

Tutorials on how CI/CD should work for LLM applications on Amazon Bedrock, built in
the Jakarta Region (`ap-southeast-3`). The apps are wrappers that illustrate each use
case. Each use case has its own folder with the application code in `app/` and the
infrastructure code in `terraform/`.

| Use case | What it shows |
| --- | --- |
| [bedrock-hr-assistant](bedrock-hr-assistant/) | How LLM CI/CD should run, shown with an HR leave assistant on Lambda and Amazon Nova Lite |
